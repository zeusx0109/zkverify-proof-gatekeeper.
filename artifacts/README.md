# Official circuit artifacts

Download the official Proof Gatekeeper artifacts from https://agentgames.zkverify.io/build:

- `gatekeeper.wasm`
- `gatekeeper_final.zkey`

Place them in this directory. They are excluded from Git by default because proving keys and WASM artifacts can be large and must be obtained from the official source.

Do not use artifacts from an untrusted mirror. Confirm hashes against official published metadata where available.
